# Quiz Game (Python & Tkinter)

Program pertama yang saya buat di kelas coding (Lesson 18): kuis pilihan ganda seputar
pemrograman dan keamanan siber, dengan tampilan jendela memakai Tkinter.

> Sengaja dibiarkan hampir seperti aslinya sebagai catatan awal belajar coding saya.
> Yang diperbaiki hanya typo dan dua soal yang faktanya keliru
> (bahasa untuk membuat sistem operasi, dan Minecraft Java Edition yang dibuat dengan Java).

## Cara main

- 10 soal pilihan ganda, klik salah satu dari 4 jawaban
- Langsung muncul pemberitahuan benar/salah, beserta jawaban yang benar
- Menang kalau skor minimal 80%

## Cara menjalankan

python quiz_game.py


Hanya butuh Python 3 (Tkinter sudah bawaan).
